Algorithm Overview
Input: Email address + Website
Output: River1River2@[number][checksum]
Step-by-Step Process
Step Action Example
1 First letter of email username → Indian River k → Krishna
2 (3rd letter of site + 1) → Indian River c + 1 = d → Damodar
3 Major value of River1 × Major value of River2 + 237 × 1 + 23 = 30
4 Checksum = sum digits until single digit 3 + 0 = 3
5 Combine: River1River2@[Step3][Step4] KrishnaDamodar@303

Worked Examples
Example 1
Input kcpd.me@gmail.com + facebook.com
Step 1 First letter 'k' → Krishna
Step 2 3rd letter of 'facebook' = 'c', c+1 = 'd' → Damodar
Step 3 K=7, D=1 → 7 × 1 + 23 = 30
Step 4 Checksum: 3 + 0 = 3
Output KrishnaDamodar@303
Example 2
Input rahul.sharma@yahoo.com + amazon.com
Step 1 First letter 'r' → Ravi
Step 2 3rd letter of 'amazon' = 'a', a+1 = 'b' → Bhagirathi
Step 3 R=4, B=9 → 4 × 9 + 23 = 59
Step 4 Checksum: 5 + 9 = 14 → 1 + 4 = 5
Output RaviBhagirathi@595
Example 3 (with vowel river)
Input test@outlook.com + netflix.com
Step 1 First letter 't' → Tapti
Step 2 3rd letter of 'netflix' = 't', t+1 = 'u' → Ulhas
Step 3 T=1, U→L=5 → 1 × 5 + 23 = 28
Step 4 Checksum: 2 + 8 = 10 → 1 + 0 = 1
Output TaptiUlhas@281
Quick Reference Card
Cut out and keep in your wallet:
FORMULA: River1 + River2 + @ + (M1×M2+23) + Checksum
River1 = 1st letter of email username
River2 = (3rd letter of site + 1)
Checksum = digit sum until single digit
Security Notes
• This system creates unique passwords for each site+email combination
• Passwords are deterministic - you can always regenerate them mentally
• Resistant to dictionary attacks and credential stuffing
